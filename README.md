## 📦 Установка

### Через HACS (рекомендуется)
1. Откройте **HACS** → **Integrations**
2. Нажмите **⋮** → **Custom repositories**
3. Добавьте:
   - **Repository**: `https://github.com/mrSaT13/YS_mrSaT`
   - **Category**: `Integration`
4. Найдите **Yandex Station (mrSaT13 fork)** → **Install**
5. Перезапустите Home Assistant
6. **Настройки** → **Интеграции** → **Добавить** → **Yandex Station**

### Вручную
```bash
# Скачайте последнюю версию
cd /config/custom_components
git clone https://github.com/mrSaT13/YS_mrSaT.git yandex_station
# Или скопируйте папку из релиза
```

## ⚙️ Настройка

Настройка **полностью аналогична оригиналу**.  
📖 **Полная документация**: [AlexxIT/YandexStation — Настройка](https://github.com/AlexxIT/YandexStation#настройка)

### Быстрый старт
```yaml
# configuration.yaml (опционально)
yandex_station:
  # Отключить облачные обновления состояний (если нужно)
  cloud_updates: true
  # Отключить локальный поиск (если не нужен)
  local_updates: true
  # Имя сервиса TTS
  tts_service_name: yandex_station_say
```

> 🔐 **Авторизация**: Рекомендуется использовать **QR-код** — это самый стабильный способ на 2026 год.

## 🎵 Особое внимание: музыка и громкость

В этой версии особое внимание уделено сценариям прослушивания музыки:

```yaml
# Пример: плавное изменение громкости без сбоя трека
script:
  volume_up_smooth:
    sequence:
      - service: media_player.volume_up
        target:
          entity_id: media_player.yandex_station_mini
        data:
          volume_step: 0.05  # малый шаг для плавности
```

✅ **Что работает стабильно:**
- Стриминг Яндекс.Музыки через локальный режим
- Регулировка громкости «на лету»
- Переключение треков без задержек
- TTS-уведомления поверх музыки (возврат к треку после объявления)

⚠️ **Что может требовать доработки:**
- Некоторые сценарии с `media_content_type: dialog`
- Интеграция с внешними сервисами (проверяйте логи)

## 🔍 Поиск и устранение проблем

1. **Включите отладочные логи**:
```yaml
logger:
  default: warning
  logs:
    custom_components.yandex_station: debug
```

2. **Проверьте статус интеграции**:  
   `Настройки` → `Система` → `Журналы`

3. **Если музыка прерывается**:
   - Убедитесь, что включён `local_updates: true`
   - Проверьте, что колонка и HA в одной подсети
   - Попробуйте задать статический IP для колонки

4. **Не работает авторизация?**  
   → Попробуйте метод QR-кода или обновите токены через перевыпуск интеграции.
